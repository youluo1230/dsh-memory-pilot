# Agent instructions

This file tells coding agents how work is tracked in this repo and where its domain documentation lives.

## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues (`youluo1230/dsh-memory-pilot`), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical triage roles, each label string equal to its name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
